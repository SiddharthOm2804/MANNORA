# Multi-Agent Civilization Framework

**NEURAL CITY — Agent System Design**

---

## 1. Agent Classification

Civilization agents in NEURAL CITY will span three archetypes in subsequent phases:

1. **Citizens**: Micro-level economic and social units with individual needs, jobs, wealth, and relationships.
2. **Institutions / Government**: Meso-level regulatory bodies issuing policies, managing taxation, public works, and zoning.
3. **Analyst / Meta-AI**: Macro-level observer measuring societal health, emergent dynamics, and systemic anomalies.

## 2. Phase 1 Scope

In Phase 1, concrete agent behaviors, economic models, and LLM queries are omitted according to project guidelines, preserving architectural clarity for foundational engine validation.
